### 🤖 Боты и ИИ

**[ai-consultant-n8n-gemini](https://github.com/GiitEnjoyer/ai-consultant-n8n-gemini)** — ИИ-консультант для сайта: n8n AI Agent + Gemini, база знаний на Python (FastAPI, BM25), встраиваемый виджет чата, заявки менеджеру в Telegram и Google Sheets. Запуск одной командой через Docker Compose, тесты и сквозной e2e.

**[freelance-bot](https://github.com/GiitEnjoyer/freelance-bot)** — Telegram-бот, который сам мониторит биржи фриланса (Kwork и др.), отбирает заказы через LLM и присылает готовый черновик отклика. Python, LLM (Ollama/OpenRouter), SQLite.

**[ai-assistant-bot](https://github.com/GiitEnjoyer/ai-assistant-bot)** — Telegram-бот «ИИ-ассистент»: отвечает на вопросы по базе знаний через RAG + LLM, показывает события календаря. Python, RAG, LLM.

**[vizitka-bot](https://github.com/GiitEnjoyer/vizitka-bot)** — Telegram-бот-визитка: мини-лендинг прямо в мессенджере с описанием услуг и кнопками связи. Python.

### ⚙️ Бэкенд и сервисы

**[payments-api](https://github.com/GiitEnjoyer/payments-api)** — платёжный микросервис на Go: счета, переводы с идемпотентностью, PostgreSQL, кеш остатков в Redis, transactional outbox и Kafka. Тесты с `-race`, манифесты Kubernetes.

**[shop-platform](https://github.com/GiitEnjoyer/shop-platform)** — микросервисы интернет-магазина на Go и полный цикл доставки в Kubernetes: Canary и Blue-Green релизы с автооткатом, SLO и burn-rate алерты, нагрузочные тесты k6.

**[price-watcher](https://github.com/GiitEnjoyer/price-watcher)** — отслеживание цен на товары по нескольким сайтам, уведомления в Telegram при снижении цены. Python, requests, BeautifulSoup, SQLite.

**[expense-tracker-api](https://github.com/GiitEnjoyer/expense-tracker-api)** — REST API для учёта расходов по категориям с помесячной сводкой. Python, sqlite3.

**[shorty](https://github.com/GiitEnjoyer/shorty)** — сервис коротких ссылок без единой внешней зависимости, только встроенный `http` модуль Node.js.

### ☁️ DevOps и инфраструктура

**[platform-infra](https://github.com/GiitEnjoyer/platform-infra)** — инфраструктура отказоустойчивой микросервисной платформы: Terraform + Terragrunt, Ansible, Kubernetes с платформенными сервисами, VictoriaMetrics/Grafana, секреты в Vault, FinOps-аудит ресурсов.

**[devops](https://github.com/GiitEnjoyer/devops)** — репозиторий-портфолио по DevOps: Linux, сети, Docker, CI/CD, Ansible, Terraform, Kubernetes, мониторинг.
